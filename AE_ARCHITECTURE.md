# Planned native architecture

Read-only snapshots -> diagnostic rules -> quantified remedy candidates -> risk/urgency ranking -> scalable advisor views.

Housing: iterate each tier from current to maximum; evaluate exact thresholds using upstream game models, no invented tier checklist; separate unmet access, inventory, desirability, expansion footprint.

Military: optional ROMAN_STRATEGY gameplay mode; army composition, terrain, supply, formation state, battle order, AI and unit simulation planned. Prototype uses coarse illustrative ratios only. Never alter Caesar III saves in-place until versioned extension serialization is tested.

Experience metrics: minimum 60 FPS target on representative city, UI interaction clarity, alert false positive rate, advisor actionable resolution, backwards compatibility. Targets are plans, not measured results.
